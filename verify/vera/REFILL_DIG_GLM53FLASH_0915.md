## 2. New findings (this pass, not in prior draft)

### N1 — HIGH: mesh receipt references an artifact that is never written
`writeMeshDryRun` mkdirs `dirname(outGlb)` but **never writes `outGlb`** — then emits a receipt with `"output": opts.outGlb`. The receipt is structurally a lie even with `dry_run: true`: any consumer scanning receipts for proof gets a plausible path to a nonexistent file. Prior Vera said "dry-run only"; the sharper defect is the **fabricated output pointer**. Drop `output` until a real file exists, or append `.missing`.

### N2 — HIGH: the standing-plate "identity lock" fails open
`assertStandingPlate` only refuses `framing === "bust"` or `source === "blockout"`. `inferFraming` returns **`"unknown"`** whenever keyword hints are absent — which is the default for any plate not generated by the two bundled prompt builders. So an actual cropped bust plate with no `bust`/`全身` keyword in its provenance text sails through into image-to-3D. This is a keyword sieve, not a gate. Fail-closed (`unknown` refuses) or stop calling it identity lock. Prior Vera's "no pipeline hook" understated this: **even hooked, it doesn't do the job claimed.**

### N3 — MEDIUM: `runAukRun` request contract is unverified against the server
It posts form fields `text` / `seed` / `prompt_wav`. The `serve-auk.py` excerpt truncates at `def run(` — param names unconfirmed. `/tts` field names are validated by crew's live usage; `/run` is not. Shipping this as ":9882-compatible" is unproven even as a lib. Pin against the server signature before any wire-up, or it's a 422 waiting to be debugged on GPU time.

### N4 — MEDIUM: refill changes live wav-lane behavior — emotion-tagged dialogue now throws
Crew `ensureAudibleShotWav` synthesizes `opts.text` raw. Refill routes it through `oneAukTake()` → `assertVerbatimTtsText`, which **throws** on `EMOTION_TAG` matches (`[...]`, `【…】`, `<emotion…>`, parenthesized cues). Fail-loud may be the right policy, but cherry-picking this file silently converts "synthesizes with tags read aloud" into "halts the wav lane mid-run." Whether SC-0915-LD0F dialogue contains markup is unverified. This must be an explicit decision, not a side effect of a file copy.

### N5 — MEDIUM: two contradictory definitions of "same world" in `h3-slots.ts`
- `sameVisualWorld`: location **+ order-sensitive `props.map(name).join("|")`** — no sort, no trim, no case fold, no dedupe. Prop order swap → "different world."
- `planH3Shot`: prevLast policy derives from **location only**. Same location + changed props → `inspect_only`, while `sameVisualWorld` says false.

Whichever call site uses which, the plan's own `prevLastFrame.policy` can contradict the module's world test. Unify or delete one.

### N6 — LOW: `aukBase` path rewriting is a config-format regression surface
Refill strips a trailing `/tts` **or `/run`** then rebuilds. Crew's resolver never invents paths (`base.endsWith("/tts") ? base : base+"/tts"`). An endpoint configured as `https://proxy.example.com/api/tts` (a /tts-only proxy) becomes `…/api/run` under refill — 404 on a config that worked on crew. Only safe if crew configs are bare-host, which is unverified.
